# Proyecto Científico: Protocolo "Cuerpo Maestro" (Yachay Tech)

**Eficacia comparativa del protocolo integral 'Cuerpo Maestro' frente a protocolos dietéticos diferenciados sobre la homeostasis metabólica y la composición corporal en adultos de 18 a 60 años con síndrome metabólico de Urcuquí e Ibarra, Imbabura, Ecuador, 2026-2027.**

- **Institución Patrocinadora y Ejecutora**: Universidad de Investigación de Tecnología Experimental Yachay (Yachay Tech).
- **Colaboradores**: Universidad Técnica Particular de Loja (UTPL) y ALFA Hospital.
- **Código del Proyecto**: PII 2026 (PII26-12).
- **Presupuesto**: \$12.499,98 USD.
- **Investigador Principal**: Paulo Roberto Navas Boada (Escuela de Ciencias Biológicas e Ingeniería).

## Características de la Plataforma Web

- **Diseño Científico y Sobrio**: Paleta editorial médica (grafito profundo, blanco nítido, verde bosque clínico y ámbar cobrizo para acentos de rigor metodológico). Libre de estilos futuristas o morados progresistas.
- **Iconografía Vectorial Limpia**: 100% libre de emojis; emplea iconos vectoriales SVG limpios y figuras esquemáticas.
- **Interactividad Clínica**:
  1. **Comparador de los 4 Brazos de Intervención**: Permite contrastar G1 (Restricción Calórica -20%), G2 (Modulación de Macronutrientes 30/40/30), G3 (Alimentación Restringida en el Tiempo TRF 16:8) y G4 (Control) con la visualización del componente transversal de "Cuerpo Maestro".
  2. **Evaluador de Síndrome Metabólico (ATP III + Lancet 2025)**: Herramienta interactiva con sliders para calcular en tiempo real el cumplimiento de los 5 criterios diagnósticos y la estadificación de adiposidad clínica.
  3. **Matriz de Operacionalización de Variables**: Tabla interactiva con búsqueda en tiempo real y filtrado por dimensiones (Antropometría, Metabolismo, Cardiovascular, Hepático/Renal, SF-36).
  4. **Cronograma Gantt Interactivo**: Visualización de los 15 meses de ejecución y filtro por Objetivos Específicos (OE1, OE2, OE3).
  5. **Gobernanza Ética y Ciegos**: Medidas rigurosas de mitigación de conflictos de interés y cumplimiento de Helsinki 2024 / CIOMS 2023 / MSP Ecuador.

## Cómo Publicar en GitHub Pages

Para ver tu página web funcionando en vivo en internet bajo la dirección `https://<tu-usuario>.github.io/<nombre-repositorio>/`, sigue estos sencillos pasos desde la terminal de tu computadora:

### Paso 1: Inicializar Git y confirmar los cambios
Abre PowerShell o Git Bash en esta carpeta (`c:\Users\Pc\Desktop\UITEY\Bioquimica del Metabolismo`):

```bash
git init
git add index.html css/ js/ assets/ README.md .nojekyll
git commit -m "Publicación de la plataforma científica Cuerpo Maestro Yachay Tech"
git branch -M main
```

### Paso 2: Conectar con tu repositorio en GitHub
Crea un nuevo repositorio en blanco en [GitHub](https://github.com/new) con el nombre que prefieras (por ejemplo `cuerpo-maestro`) y ejecuta:

```bash
git remote add origin https://github.com/<TU_USUARIO_GITHUB>/cuerpo-maestro.git
git push -u origin main
```

### Paso 3: Activar GitHub Pages
1. En GitHub, ingresa a tu repositorio recién subido.
2. Haz clic en la pestaña **Settings** (Configuración) arriba a la derecha.
3. En el menú lateral izquierdo, selecciona **Pages**.
4. En **Branch**, selecciona `main` y la carpeta `/ (root)`.
5. Haz clic en **Save**.

En 1-2 minutos, GitHub te proporcionará el enlace público directo:
```
https://<TU_USUARIO_GITHUB>.github.io/cuerpo-maestro/
```
